# Roadmap

| Phase | Scope |
| --- | --- |
| 0 · Infrastructure | Extension package, sidebar, translation, Blender tests and CI |
| 1 · Core workflow | STL, scale, straight cut, cylindrical and hexagonal connectors, validation, per-part STL |
| 2 · Planning | Persistent draft operations, curved and freehand cuts, polygons, custom and loose connectors, OBJ/FBX, repair and updates |
| 3 · Print preparation | Printer profiles, fit checks, base and color separation, symmetry, regions, placement, calibrations, exploded view, 3MF |
| 4 · Professional tools | Magnets, dovetails, snap-fits, articulations, glue features, hollowing, drains, thickness, costs and assembly guides |
| 5 · Automation | Smart Split, seam suggestions, orientation, bed layout, segmentation and stress testing |

Each phase requires Blender tests, documentation and a descriptive commit. The roadmap tracks development and does not imply validation on any Blender version.
