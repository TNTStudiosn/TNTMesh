# Contributing

Open an issue with the Blender version, operating system, expected behavior and reproduction steps. Include a shareable .blend file or a generated example mesh if geometry matters. Check that you have permission to share any model you attach.

Run lint and the Blender integration suite described in [development](docs/development.md). Include the geometry and rollback regressions relevant to your patch. Contributions are distributed under GPL-3.0-or-later.
